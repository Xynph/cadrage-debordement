# Témoin isolé auto-release

Ce fichier est un témoin technique sans effet sur le jeu, les sauvegardes, les workflows ou les données Rugby Réel.

Il sert exclusivement à vérifier le dispositif d'intégration automatique en mode `trial`, avec une PR et un SHA exacts, sous les protections GitHub et le gate officiel.

La présence de ce fichier ne constitue ni une autorisation d'activation générale, ni une preuve de fusion automatique réussie.
