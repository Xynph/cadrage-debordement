# V49 — facilities

Module de préparation **hors match**. Calculs fictifs, déterministes et sans effet secondaire ; aucun changement des sauvegardes ni de l'interface. API CDFacilities exposée en CommonJS et navigateur. Ce composant n'est pas encore intégré à une carrière : il faut explicitement relier ses entrées aux données validées du jeu et tester la migration avant activation.

Exécuter : `node tests/facilities.cjs`. Les limites et barèmes sont des hypothèses de game design, non des règles officielles ou données réelles.
