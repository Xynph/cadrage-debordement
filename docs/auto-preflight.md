# Précontrôle automatique des intégrations ordinaires

Le précontrôle historique relisait la CI à chaque tête verte et renvoyait vers
une commande dans l’issue #73. Le résultat de CI se consulte dans la PR.
Pour vérifier un lot ordinaire avant fusion, l’intégrateur utilise le mode
**check** de [l’intégration ordinaire](auto-release.md).
