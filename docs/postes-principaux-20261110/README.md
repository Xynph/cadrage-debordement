# Postes principaux sans doublons

Le poste principal couvre les numéros 4–5, 6–7, 11–14 ou 12–13 selon le rôle. Ces numéros ne figurent plus dans Autres. Le numéro 8 demeure un rôle distinct. Pour un pilier, les côtés 1 et 3 sont regroupés uniquement si ses qualifications existantes les autorisent ; le libellé devient alors Pilier G/D. Le talonnage reste distinct.

La projection publie primaryPositions en plus du numéro primaire historique. Les notes au poste, les qualifications et les calculs de match ne changent pas. L’interface utilise ce groupe pour le texte, l’infobulle et le tri, en conservant les positions sources.

Réception : test rouge puis vert sur les cinq groupes ; intégration composition/import/reprise et calculs match verts ; 235 contrôles graphiques en 2560×1440, vraie carrière, profil inchangé en consultation. Un premier lancement graphique a échoué car le serveur X privé était fermé ; il a été relancé avant la réception. Capture réelle jointe. Base c15a6e9/PR535 ; aucune fusion main.

Saison simulée 2026–2027 ; correction de classement des postes de jeu, sans changement des règles d’éligibilité ni des protections de première ligne (référence World Rugby loi3 déjà lue).
