# DATA-05 Hybrid — collecte HTTP directe puis secours Firecrawl

Script autonome `tools/data05-hybrid.cjs` : `collect({players,dir,direct,firecrawl,concurrency,delayMs,limit,firecrawlBudget})`. Lire les 1 592 joueurs depuis `modding/data03/*.json` et fournir pour chacun `{id,club,url}`. Cache par ID dans le répertoire `dir` ; écriture atomique, export `profiles.json` et `report.json` ; export de tous les IDs manquants. Prévoir un adaptateur Firecrawl utilisant les paramètres et la clé du compte, sans committer de secret. Concurrency limitée de 1 à 4, délai par travailleur par défaut 1 seconde, plafond de tentatives Firecrawl global. La méthode `direct` lit d'abord un document HTML public ; l'extraction n'est validée que si le nom et l'âge sont lisibles. Ne jamais accéder aux espaces authentifiés ni contourner les limitations réseau, les CAPTCHA, les erreurs 403/429 ou les robots du site : vérifier les règles avant toute campagne.

**Vérification environnement au 31/10/2026 :** `node -v` : v22.16.0. Les requêtes HTTPS `top14.lnr.fr/robots.txt` et `/joueur/862-barnabe-massa` depuis le conteneur ont échoué à la connexion. **Aucune collecte HTTP directe complète n'a donc été lancée.** Les tests Node avec doubles HTTP ont été réellement exécutés (3/3 succès, selon sortie du conteneur), mais ne démontrent pas l'accès HTTP live. Aucune collecte Firecrawl payante via ce script ; crédits restants observés avant test : **748**.

**Limitations importantes** : le module fournit le moteur de collecte hybride et des tests injectés, mais pas encore d'interface CLI complète ni d'import automatique des 240 profils précédemment collectés. Un profil ne contient que les éléments visibles ; la date de naissance et l'affiliation au 01/07/2026 sont non vérifiées. Ne pas lancer de campagne sans accès autorisé, validation des conditions de consultation et connexion réseau effective. Le site peut être rendu côté client : une page HTTP dépourvue de champs devra être signalée comme incomplète.

Aucune modification `dist/**`, aucune sauvegarde ou fusion. Dépendance documentaire sur PR #129 non fusionnée ; l'intégrateur contrôle les CI séparément.
